🎯 Widget Integration Examples

This page demonstrates how to integrate the Tugo Widget using script tags. Open the browser console to see initialization logs.

Example 1: Auto-initialization

Widget automatically initializes when the script loads with data-auto-init="true".

<script src="dist/widget.iife.js" data-widget-id="example" data-container-id="widget-1" data-auto-init="true"></script>

Example 2: Manual Initialization

Widget is initialized programmatically using window.TugoWidget.init().

window.TugoWidget.init({ containerId: 'widget-2', widgetId: 'example', theme: 'dark' });

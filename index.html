🖼️ Widget Iframe Integration Examples

This page demonstrates how to integrate the Tugo Widget using iframes. The widget is loaded in an isolated context with configuration passed via query parameters.

Example 1: Light Theme

Basic iframe integration with light theme.

<iframe src="../dist/iframe.html?widgetId=example&theme=light&apiBaseUrl=https://api.example.com" style="width: 100%; height: 500px; border: 0;" ></iframe>

Example 2: Dark Theme

Iframe integration with dark theme.

<iframe src="../dist/iframe.html?widgetId=example&theme=dark&apiBaseUrl=https://api.example.com" style="width: 100%; height: 500px; border: 0;" ></iframe>

Example 3: Custom Primary Color

Iframe integration with custom primary color.

<iframe src="../dist/iframe.html?widgetId=example&theme=light&primaryColor=%23ff6b6b&apiBaseUrl=https://api.example.com" style="width: 100%; height: 500px; border: 0;" ></iframe>

📝 Query Parameter Reference

Available query parameters for iframe integration:

  • widgetId - Widget identifier (required)
  • theme - Theme: light or dark
  • primaryColor - Primary color (URL-encoded hex, e.g., %23ff6b6b)
  • apiBaseUrl - API base URL
  • apiKey - Optional API key for authentication
